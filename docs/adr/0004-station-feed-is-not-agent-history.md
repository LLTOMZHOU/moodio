# Keep the Station feed separate from agent conversation history

The Station feed records durable domain facts and selected Direct responses. A direct Listener control goes immediately through the Station controller and is persisted as a Station event. Meaningful direct controls additionally create a compact, invisible Internal Station-event item in the shared DJ session with a `developer` role. It is explicitly application context, not a synthetic Listener request, and it does not invoke a DJ run or require acknowledgement.

The `developer` role is the initial model projection, not a claim that its instruction bias is ideal. A future harness experiment will compare it with a hidden `user`-role message explicitly labelled as a non-conversational Listener action. The comparison evaluates action use, unwanted acknowledgement, and provider/model-specific behavior; the same durable Station event drives both variants.

Dynamic system instructions carry only stable DJ policy, the compact Listener profile, and a tiny run header. The DJ reads live Queue state through `get_queue()` before programming it; the compact result contains revision, playback/current-item state, and ordered upcoming item type, origin, and anchor relationship, but no provider URLs or raw event history. Queue mutations require the returned revision and reject stale or immediate duplicate work. Other live operational detail stays behind scoped tools. This lets the session retain a useful chronology of direct Listener actions and actual tool observations without turning either it or the user-visible feed into the Station's source of truth.

The UI owns presentation of event kinds: by default it exposes broad, human-readable Station activity as cards or transient lines. It renders meaningful Listener controls and profile revisions as quiet activity cards, a Direct response as a conversation item, and raw tool calls/arguments/results, hidden session items, and chain-of-thought not at all. A later preference may hide visible categories without changing the feed or session records.
