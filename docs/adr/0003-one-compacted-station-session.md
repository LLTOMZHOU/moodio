# Use one compacted Station session for the DJ

Every bounded DJ run for a Station continues one shared Agents SDK session. A small app-owned, file-backed implementation of the session interface is wrapped in `OpenAIResponsesCompactionSession`, configured with an inexpensive compaction model and a generous trigger threshold so the conversation remains coherent without unbounded prompt growth. Natural-language Listener messages enter it as user turns. Meaningful direct Listener controls create a compact Internal Station-event item with a `developer` role; if a run is in flight, that projection is enqueued and flushed at the next safe session boundary. These controls do not invoke a run or masquerade as Listener text. The Listener profile, Station tasks, program state, and event history remain the durable source of truth because a compacted conversation is still a summary.
